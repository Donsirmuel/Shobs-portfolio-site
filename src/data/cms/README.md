# Decap CMS Content Folder

This folder will contain content managed through Decap CMS.

When you create or edit content through the admin panel at `/admin`, the files will be stored here in markdown format.

## Structure

- `projects/` - Project case studies
- `blog/` - Blog posts
- `testimonials/` - Client testimonials

Each piece of content is stored as a separate markdown file with frontmatter containing the structured data.
